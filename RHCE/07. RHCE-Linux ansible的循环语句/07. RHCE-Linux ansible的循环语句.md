- shell脚本中, 使用for、while循环、until循环
- 在ansible中, 利用三个关键字来实现循环
	- with 系列, 属于 withx 关键字的, 通过 with 的方式实现循环
		- with_items : 循环列表
		- with_dict : 循环字典
- 在2.5版本之后, 推荐使用loop关键字实现循环. 默认支持列表循环的, 如果要支持字典循环的话需要借助一个jinja2过滤器来转换格式

# 1. with_items 循环列表
- 案例 : 通过 with_items 关键字实现 file1 到 file4 文件的批量创建, 使用 file 模块使用
	- 方式1
		- ```yaml
			使用 with_items. 定义一个变量, 这个变量的值是列表
			- name: play
			  hosts: all
			  vars:
			    files:
			      - file1
			      - file2
			      - file3
			      - file4
			  tasks:
			  - name: task
			    file:
			      name: "{{ item }}"
			      state: touch
			    with_items: "{{ files }}"
			    
			使用 loop. 定义一个变量, 这个变量的值是列表
			- name: play
			  hosts: all
			  vars:
			    files:
			      - file1
			      - file2
			      - file3
			      - file4
			  tasks:
			  - name: task
			    file:
			      name: "{{ item }}"
			      state: touch
			    loop: "{{ files }}"
		  ```
	- 方式2
		- ```bash
			使用 with_items. 直接在 with_items 关键字下面写上要循环的内容
			- name: play
			  hosts: all
			  tasks:
			  - name: task
			    file:
			      name: "{{ item }}"
			      state: touch
			    with_items:
			    - file1
			    - file2
			    - file3
			    - file4
			      
			使用 loop. 直接在 loop 关键字下面写上要循环的内容
			- name: play
			  hosts: all
			  tasks:
			  - name: task
			    file:
			      name: "{{ item }}"
			      state: touch
			    loop:
			    - file1
			    - file2
			    - file3
			    - file4
		  ```

# 2. with_dict 循环字典
- 字典, 对象 : 以键值对的方式存在的, 在 yaml 中, key: value 就是字典类型
	- ```yaml
		- name: play
		  hosts: all
		  vars:
		    name:
		      name1: user1
		      name2: user2
		      name3: user3
		      name4: user4
		  tasks:
		  - name: task
		    debug:
		      msg: "{{ item }}"
		    with_dict: "{{ name }}"
	  ```
	- 输出结果
		- ```bash
			ok: [node1] => (item={'key': 'name1', 'value': 'user1'}) => {
			    "msg": {
			        "key": "name1",
			        "value": "user1"
			    }
			}
			ok: [node1] => (item={'key': 'name2', 'value': 'user2'}) => {
			    "msg": {
			        "key": "name2",
			        "value": "user2"
			    }
			}
			ok: [node1] => (item={'key': 'name3', 'value': 'user3'}) => {
			    "msg": {
			        "key": "name3",
			        "value": "user3"
			    }
			}
			ok: [node1] => (item={'key': 'name4', 'value': 'user4'}) => {
			    "msg": {
			        "key": "name4",
			        "value": "user4"
			    }
			}
			ok: [node2] => (item={'key': 'name1', 'value': 'user1'}) => {
			    "msg": {
			        "key": "name1",
			        "value": "user1"
			    }
			}
			ok: [node2] => (item={'key': 'name2', 'value': 'user2'}) => {
			    "msg": {
			        "key": "name2",
			        "value": "user2"
			    }
			}
			ok: [node2] => (item={'key': 'name3', 'value': 'user3'}) => {
			    "msg": {
			        "key": "name3",
			        "value": "user3"
			    }
			}
			ok: [node2] => (item={'key': 'name4', 'value': 'user4'}) => {
			    "msg": {
			        "key": "name4",
			        "value": "user4"
			    }
			}
		  ```
	- 如果要循环的内容是key, 那么 "{{ item.key }}"
	- 如果要循环的内容是value, 那么"{{ item.value }}"


- loop关键字要循环字典的话, 需要借助外部的工具来实现, 这个工具就是jinja2过滤器
- jinja2过滤器就是实现格式转换的, 比如可以将明文转换为加密后的密文, 比如可以将数字转换为字母
- 比如将大写字母转换为小写字母...比如可以将字典格式转化为列表格式
- **格式："{{ 变量名 | jinja2过滤器 }}"** 
	- ```yaml
		loop: "{{ users | dict2items }}"
	  ```
