# 1. 条件判断应用场景
- 应用场景
	- ```bash
		在有的时候play的结果依赖于变量、fact或者是前一个任务的执行结果，或者基于上一个task执行返回的结果而决定如何执行后续的task，这个时候就需要用到条件判断。 
		条件语句在Ansible中的使用场景： 
			在目标主机上定义了一个硬限制，比如目标主机的最小内存必须达到多少，才能执行该task 
			捕获一个命令的输出，根据命令输出结果的不同以触发不同的task 
			根据不同目标主机的facts，以定义不同的task 
			根据目标机的cpu的大小，以调优相关应用性能 
			用于判断某个服务的配置文件是否发生变更，以确定是否需要重启服务
	  ```
- **条件判断语句的语法** 
	- ```bash
		when: 运算符
		when关键字后面的内容默认就会识别为变量, 所以我们在引用变量的时候无论是自定义的、fact事实变量、魔法变量都不要加上 "{{ }}"
	  ```

# 2. 比较运算符

## 2.1 数字比较运算符
- 运算符
	- ```markdown
		# > : 比较两个对象的大小，左边的值大于右边的值，则为真
		# < : 比较两个对象的大小，左边的值小于右边的值，则为真
		# >= : 比较两个对象的大小，左边的值大于等于右边的值，则为真
		# <= : 比较两个对象的大小，左边的值小于等于右边的值，则为真
	  ```
- 案例1 : 当被控节点剩余空闲内存空间小于500M的时候, 就不要执行task任务
	- ```yaml
		- name: when1
		  hosts: all
		  tasks:
		  - name: task1
		    debug:
		      msg: 这是我第一次使用when条件判断的语句
		
		  - name: task2
		    debug:
		      msg: ok
		    when: ansible_memfree_mb > 500
	  ```
- 案例2 : 当被控节点操作系统版本大于等于8, 那么就执行配置2个仓库的task任务
	- ```yaml
		- name: when2
		  hosts: all
		  tasks:
		  - name: configure repository <= 7
		    yum_repository:
		      file: dvd
		      name: dvd
		      description: dvd
		      baseurl: file:///media
		      gpgcheck: 0
		      enabled: 1
		    when: ansible_distribution_major_version <= '7'
		  - name: configure repository  >= 8
		    yum_repository:
		      file: dvd
		      name: BaseOS
		      description: baseos
		      baseurl: file:///media/BaseOS
		      gpgcheck: 0
		      enabled: 1
		    when: ansible_distribution_major_version >= '8'
		
		  - name: configure repository  >= 8
		    yum_repository:
		      file: dvd
		      name: AppStream
		      description: appstream
		      baseurl: file:///media/AppStream
		      gpgcheck: 0
		      enabled: 1
		    when: ansible_distribution_major_version >= '8'
	  ```

## 2.2 字符串比较运算符
- 运算符
	- ```markdown
		# == : 比较两个对象是否相等，相等则返回真。可用于比较字符串和数字
		# != : 比较两个对象是否不等，不等则为真。
	  ```
 - 案例1 : 当被控节点主机名是node1的时候，那么执行debug模块的任务，输出node1 ok 
	- ```yaml
		- name: when3
		  hosts: all
		  tasks:
		  - name: task1
		    debug:
		      msg: node1 ok
		    when: inventory_hostname == 'node1'
		
		  - name: task2
		    debug:
		      msg: 所有主机都会输出ok；
	  ```
- 案例2 : 当被控节点操作系统不是RedHat的时候, 那么执行debug模块的任务, 输出not redhat 
	- ```yaml
		- name: when3
		  hosts: all
		  tasks:
		  - name: task1
		    debug:
		      msg: not redhat
		    when: ansible_os_family != 'RedHat'
	  ```

# 3.字符串比较
- 运算符
	- ```bash
		and : 逻辑与, 当左边和右边两个表达式同时为真, 则返回真
		or : 逻辑或, 当左右和右边两个表达式任意一个为真, 则返回真
		not : 逻辑否, 对表达式取反
		() : 当一组表达式组合在一起, 形成一个更大的表达式, 组合内的所有表达式都是逻辑与的关系
	  ```
- 案例1 : 只有当操作系统版本是RedHat并且主机的空闲内存大于100M的, 才执行task1任务 
	- ```yaml
		- name: when4
		  hosts: all
		  tasks:
		  - name: task1
		    debug:
		      msg: ok
		    when: ansible_os_family == 'RedHat' and ansible_memfree_mb > 100
	  ```
- 案例2 : 主机名叫做node1的或者主机的内存空间大于1000M的, 才执行task1任务
	- ```yaml
		- name: when4
		  hosts: all
		  tasks:
		  - name: task1
		    debug:
		      msg: ok
		    when: inventory_hostname == 'node1' or ansible_memtotal_mb > 100
	  ```
- 案例3 : 当主机操作系统是RedHat并且主机名是node1的, 或者, 主机剩余内存空间大于100M的并且操作系统版本是大于等9的, 才会执行task1任务
	- ```yaml
		- name: when4
		  hosts: all
		  tasks:
		  - name: task1
		    debug:
		      msg: ok
		    when: ( ansible_os_family == 'RedHat' and inventory_hostname == 'node1' ) or ( ansible_memfree_mb > 100 and ansible_distribution_major_version >= '9' )
	  ```

# 4. 配合 register 注册变量进行判断
- register注册变量和判断语句联合使用 : 都是用来判断前面一个task任务是否执行成功, 然后再决定是否要执行后面的task任务
	- ```bash
		- name: register
		  hosts: all
		  tasks:
		    - name: create
		      user:
		        name: aabbcc
		      register: status
		
		    - name: use debug
		      debug:
		        msg: ok
		      when: status.failed == false
		      
		      
		# 另一个
		- name: register
		  hosts: all
		  tasks:
		  - name: tasks1
		    shell: rm -rf /tmp/*
		    register: status
		
		  - name: use debug
		    debug:
		      msg: "{{ status }}"
		
		  - name: tasks2
		    shell: touch /tmp/abc
		    when: status.rc == 0
	  ```

# 5. 文件属性运算符 
- 文件属性运算符
	- ```bash
		file : 判断指定路径是否为一个文件, 是则为真
		directory : 判断指定路径是否为一个目录, 是则为真
		link : 判断指定路径是否为一个软链接, 是则为真
		mount : 判断指定路径是否为一个挂载点, 是则为真
		exists : 判断指定路径是否存在, 存在则为真
		特别注意 : 关于路径的所有判断均是判断主控端上的路径, 而非被控端上的路径
	  ```
- 案例 : 如果被控节点不存在/opt/passwd文件, 则把被控节点自己的/etc/passwd拷贝过去
	- ```yaml
		- name: file
		  hosts: all
		  tasks:
		  - name: task
		    shell: ls /opt/passwd
		    ignore_errors: yes
		    register: status
		
		  - name: task1
		    copy:
		      remote_src: yes
		      src: /etc/passwd
		      dest: /opt/passwd
		    when: status.rc != 0
	  ```
- 案例 : 如果控制节点不存在/opt/passwd文件, 则把被控节点自己的/etc/passwd拷贝到/opt/目录下
	- ```yaml
		- name: file
		  hosts: all
		  tasks:
		  - name: task1
		    copy:
		      remote_src: yes
		      src: /etc/passwd
		      dest: /opt/passwd
		    when: not '/opt/passwd' is exists
	  ```

# 7. in 关键字判断
- **判断关键字是否在另外一个关键字中** 
- 判断内容是否在一个列表中
	- ```yaml
		- name: file
		  hosts: all
		  vars:
		   name1:
		    - a
		    - b
		    - c
		  tasks:
		  - name: tasks
		    debug:
		      msg: ok
		    when: "'a' in name1"
	  ```
	- ```yaml

		如果被控节点存在/dev/vdb设备，则进行分区
		- name: file

		   name1:
		    - a
		    - b
		    - c
		  tasks:

		      msg: ok

	  ```

# 8. 根据任务执行结果判断
- ```yaml
	- name: register
	  hosts: all
	  tasks:
	  - name: create user
	    user:
	      name: aabbcc
	      state: present
	    register: status
	
	  - name: use debug
	    debug:
	      msg: ok
	    when: status is success  # 当任务执行成功则判断ok
	    
	 配合register注册变量
	   status is success/changed/skip/failed
  ```

# 9. 其他的运算符
- ```yaml
	判断字符串：
	lower：判断字符串中的所有字母是否都是小写，是则为真
	upper：判断字符串中的所有字母是否都是大写，是则为真
	
	
	示例：
	- hosts: test
	  gather_facts: no
	  vars: 
	    str1: "abc"
	    str2: "ABC"
	  tasks:
	    - debug:
	        msg: "str1 is all lowercase"
	      when: str1 is lower
	    - debug:
	        msg: "str2 is all uppercase"
	      when: str2 is upper
  ```
- ```yaml
	判断整除：
	even：判断数值是否为偶数，是则为真
	odd：判断数值是否为奇数，是则为真
	divisibleby(num)：判断是否可以整除指定的数值，是则为真
	
	
	- hosts: test
	  gather_facts: no
	  vars: 
	    num1: 6
	    num2: 8 
	    num3: 15
	  tasks:
	    - debug: 
	        msg: "num1 is an even number"
	      when: num1 is even
  ```
- ```yaml
	其他条件测试：
	subset 判断一个list是不是另一个list的子集：when: a is subset(b)
	superset 判断一个list是不是另一个list的父集：when: b is superset(a)
	string 判断对象是否为一个字符串，是则为真  when: var1 is string
	number 判断对象是否为一个数字，是则为真  when: var3 is number

  ```
