# 1. jinja2 模板
- 这个模板实际上是一个带有ansible的变量和判断、循环语句的**一个文件** 
- 大多数的情况下, 被控节点修改配置文件的话, 其实只有一部分的内容是不一样的, 其余的内容是完全一样的, 可以利用jinja2模板文件来实现管理
- jinja2模板就是一个**带有变量内容的文本文件**, 下发到被控节点的时候会自动将其变量渲染会具体的值
- **要传输jinja2模板文件, 一定要使用template模块, 因为template模块支持将模板文件中的变量、循环、判断渲染出来** 
	- ```yaml
		- name: jinja2
		  hosts: all
		  tasks:
		  - name: jinja2
		    template:
		      src: httpd.conf.j2
		      dest: /etc/httpd/conf/httpd.conf
		[root@mubai632 ~]# grep 'ansible_' httpd.conf.j2
		Listen {{ ansible_ens160.ipv4.address }}:80
	  ```

- 判断语句
	- 有一些情况下, 被控节点有多张网卡, 你想要优先让其监听在ens224网卡上, 如果没有ens224网卡, 那么就监听到ens160网卡上, 如果ens160网卡也不存在, 那么就监听在所有的网卡IP地址上
	- 语法格式
		- ```yaml
			{% if 条件表达式 %}
			执行语句1
			{% elif 条件表达式 %}
			执行语句2
			.....
			{% else %}
			执行语句
			{% endif %}
		  ```

		- ```yaml
			{% if ansible_ens224 is defined %}
			Listen {{ ansible_ens224.ipv4.address }}:80
			{% elif ansible_ens160 is defined %}
			Listen {{ ansible_ens160.ipv4.address }}:80
			{% else %}
			Listen 80
			{% endif %}
		  ```

- 循环语句
	- 语法格式
		- ```yaml
			{% for 变量名 in 要循环的值 %}
			内容
			{% endfor%}
		  ```
		- ```yaml
			[root@mubai632 ~]# cat hosts.j2
			127.0.0.1   localhost localhost.localdomain localhost4 localhost4.localdomain4
			::1         localhost localhost.localdomain localhost6 localhost6.localdomain6
			{% for hosts in groups.all %}
			{{ hostvars[hosts].ansible_ens160.ipv4.address }} {{ hostvars[hosts].inventory_hostname }}
			{% endfor %}
			
			# groups.all groups魔法变量, 主机清单中的主机, .all 所有主机
			# hostvars 魔法变量, 获取指定主机的fact事实变量
		  ```

# 2. jinja2 过滤器
- **jinja2 过滤器实现的功能是转换** 
- 语法格式
	- ```yaml
		"{{ 变量名 | jinja2过滤器 }}"
	  ```
	- **default 过滤器 : 如果变量未定义, default 过滤器会默认赋予一个值** 
		- ```yaml
			格式
				"{{ 变量名 | default('值') }}"
				
			- name: default
			  hosts: all
			  vars:
			    var1: rhel9  # 没有这行就会输出 nihao
			  tasks:
			  - name: task
			    debug:
			      msg: "{{ var1 | default('nihao') }}"
		  ```
	- **password_hash 过滤器 : 进行加密的. 采用不同的加密方式对变量的值进行加密, 通常应用在用户创建的时候给用户设置密码的场景** 
	- **dict2items 过滤器**
