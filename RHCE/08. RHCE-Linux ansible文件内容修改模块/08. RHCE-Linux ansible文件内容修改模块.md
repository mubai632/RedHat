# 1. lineinfile 模块
- **针对于文件内容修改的模块, 仅支持一次修改、删除一行内容. 不能对关键字操作, 只能操作一整行内容** 
- 常用参数
	- ```bash
		path : 要修改的文件
		regexp : 正则表达式匹配要修改的行
		line : 修改或者插入行的内容
		insertbefore : 在匹配的行前面插入
		insertafter : 在匹配的行后面插入
		backup : 是否备份文件
		create : 文件不存在则创建文件
		validate : 验证文件修改的有效性, 需要文件自带验证机制
		  比如如果修改的是httpd配置文件, 校验的时候其实是调用httpd命令自己做校验
		  比如如果修改的是sudo配置文件, 校验的时候其实是调用sudoedit方式来校验
		  就是说，本身lineinfile不做校验机制, 它是调用修改的配置文件本身的校验来实现校验的
		backrefs : 如果为false, 那么regexp没有匹配到的内容则会在文件末尾新, 如果为yes, 那么regexp必须严格匹配上, 如果没有匹配上则什么都不做
	  ```
- 案例1 : 将所有的被控节点永久关闭SELinux
	- ```yaml
		- name: lineinfile
		  hosts: all
		  tasks:
		  - name: task1
		    lineinfile:
		      path: /etc/selinux/config  #表示我要操作的文件是什么
		      regexp: ^SELINUX=   # 表示我要匹配的关键字所在的行
		      line: SELINUX=disabled  # 表示我要替换关键字所在行的所有的内容
		      backup: yes  # 备份
	  ```
- 案例2 : 修改sshd配置文件, 在#Port 22下面或者上面添加一行内容 Port 2222
	- ```yaml
		# 在行的后面插入
		- name: lineinfile
		  hosts: all
		  tasks:
		  - name: task1
		    lineinfile:
		      path: /etc/ssh/sshd_config
		      insertafter: ^#Port 22
		      line: Port 2222
		      backup: yes
		      
		# 在行的前面插入
		- name: lineinfile
		  hosts: all
		  tasks:
		  - name: task1
		    lineinfile:
		      path: /etc/ssh/sshd_config
		      insertbefore: ^#Port 22
		      line: Port 2222
		      backup: yes
	  ```
- 案例3 : 修改http的配置文件后, 校验文件
	- ```yaml
		- name: lineinfile
		  hosts: all
		  tasks:
		  - name: task1
		    lineinfile:
		      path: /etc/httpd/conf/httpd.conf
		      regexp: askldadhkjjahdkjlasd
		      line: Port 22
		      backrefs: false
		      validate: httpd -t -f %s  # 固定格式%s代表需要校验的文件
	  ```

# 2. blockinfile 模块
- 针对于文件内容修改的模块, 支持多行内容修改、删除操作
- 和lineinfile模块的参数一样，多了2个参数
	- ```bash
		block：操作内容
		marker：标记
	  ```
- 案例
	- ```yaml
		- name: blockinfile
		  hosts: all
		  tasks:
		  - name: task
		    blockinfile:
		      path: /opt/abc
		      create: yes
		      block: |    # 固定语法
		        abc
		        123
		        456
		    
		
		[root@mubai632 ~]# cat /opt/abc
		# BEGIN ANSIBLE MANAGED BLOCK
		abc
		123
		456
		# END ANSIBLE MANAGED BLOCK
		# 会多出上下两行的标记
	  ```
- 删除多行内容
	- ```yaml
		- name: blockinfile
		  hosts: all
		  tasks:
		  - name: task
		    blockinfile:
		      path: /opt/abc
		      create: yes
		      marker: "# {mark} ANSIBLE MANAGED BLOCK"  # 使用标记进行删除
		      state: absent
	  ```
