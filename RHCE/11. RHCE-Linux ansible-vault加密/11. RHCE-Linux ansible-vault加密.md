# ansible-vault 加密
- ansible-vault 可以针对任何文件进行加密, 比如playbook、比如变量文件、比如jinja2模板文件
- ansible-vault 帮助文档
	- ```bash
		[root@adsl-172-10-0-153 ansible]# ansible-vault --help
		usage: ansible-vault [-h] [--version] [-v] {create,decrypt,edit,view,encrypt,encrypt_string,rekey} ...
		
		encryption/decryption utility for Ansible data files
		
		positional arguments:
		  {create,decrypt,edit,view,encrypt,encrypt_string,rekey}
		    create : 创建一个新的加密文件, 会自动进入vim编辑器中, 保存后会要求输入密码
		    decrypt : 解密
		    edit : 编辑一个加密的文件, 类似于vim编辑文件
		    view : 查看加密内容, 需要输入密码
		    encrypt : 加密一个已经存在的文件
		    encrypt_string : 加密字符串
		    rekey : 重新设置密码
		
		optional arguments:
		  --version             show program's version number, config file location, configured module search
		                        path, module location, executable location and exit
		  -h, --help            show this help message and exit
		  -v, --verbose         Causes Ansible to print more debug messages. Adding multiple -v will increase
		                        the verbosity, the builtin plugins currently evaluate up to -vvvvvv. A
		                        reasonable level to start is -vvv, connection debugging might require -vvvv.
		
		See 'ansible-vault <command> --help' for more information on a specific command.
	  ```
- 一旦使用ansible对文件加密了, 千万不用通过编辑工具直接去编辑内容, 因为会造成文件内容丢失
- 只能够通过ansible-vault命令进行编辑加密的文件
