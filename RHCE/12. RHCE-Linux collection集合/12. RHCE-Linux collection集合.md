# 集合的介绍
- 集合的概念是从ansible-core版本开始的, 也就是从ansible2.10版本开始
- 集合又可以称之为collection, 集合中包括plugins、roles、modules
- 相当于把原来一个完整的ansible拆分为了俩个部分, 一个是ansible-core, 一个是collection
- ansible2.9以及之前的版本, 模块的名字就是 : 模块名, yum
- ansible-core版本开始, 模块的名字变成了 : 命令空间.集合名.模块名, ansible.builtin.yum
- 集合管理的命令 **`ansible-galaxy`** 
- 集合的默认搜索和下载路径 **`https://galaxy.ansible.com/`** 
- 只有把集合安装到对应的目录下, ansible才能识别到这些集合中的模块等内容
	- 修改配置文件
		- ```bash
			# 由ansible.cfg配置文件决定的, collections_path=参数
			collections_path=自定义的collections位置:/usr/share/ansible/collections
			
			#安装集合
			ansible-galaxy collection install community.general
			通过文件方式来实现集合的安装，批量安装集合
			[root@server ~]# cat 123.yaml
			- name: 1
			  src: http://xxxxxx
			- name: 2
			  src: http://xxxxxx
			执行命令: ansible-galaxy collenction install -r 123.yaml
			
			#列出集合
			ansible-galaxy collection list
			
			#删除集合
			直接删除目录即可
		  ```
