**locate** : 根据数据库查找文件 **`locate 文件名`** 
	数据库来源 **/var/lib/mlocate/mlocate.db** , 找不到数据就更新数据 `updatedb` 
**find**: 在指定目录实时查找文件 **`find 目录 条件`** 
which: 查找命令所在位置 **`which 命令`** 
	查找 PATH 环境变量中的命令位置(只查 PATH 目录, 只找命令)
whereis: 查找命令的相关文件 **`whereis 命令`**
	会找到 二进制文件, 源码包, 帮助文档 
	查找内容 binary source man手册 

# 1. locate-文件查找工具
- locate 特点: 
	1. 根据关键字搜索(模糊查找), 只要文件名称包含这个关键字就可以搜索到
	2. 根据数据库索引文件搜索, 如果数据库的索引文件不存在则无法使用(需要执行 **`updatedb`** 命令来更新数据库索引文件)
		- ```bash
			[root@rhel9 cron]# locate passwd # 报错
			locate: can not stat () `/var/lib/mlocate/mlocate.db': No such file or directory
		  ```
	3. locate **不是实时查询**, 有可能有的文件明明存在但是无法查询到(要么就等待自己更新数据库索引, 要么手动执行updatedb命令更新)
		- ```bash
			[root@rhel9 opt]# touch passwd-yutianedu 
			[root@rhel9 opt]# locate passwd-yutianedu 
			[root@rhel9 opt]#updatedb
			[root@rhel9 opt]# locate passwd-yutianedu 
			/opt/passwd-yutianedu
		  ```
	4. 所有查找工具共同的特点, 查找的目录必须要有 **r** 和 **x** 权限 
- 优点 : 根据索引进行搜索, 查询效率快 
- 缺点 : 无法实时去搜索文件 
- 常用选项
	- ```bash
		locate -i 忽略关键字的大小写
		locate -nx 列出指定n行
	  ```
- 使用场景: 文件非常的多, 只知道文件名包含的关键字, locate 查询速度快

# 2. find-文件查找工具
find特点: 
1. 实时查询文件, 精确查询, 也可以进行模糊查询(支持各种通配符)
2. find工具可以在查找到文件的基础之上执行二次命令操作(比如搜索系统上所有以.swp结尾的文件, 然后去删除掉)
3. find支持各种条件查询(根据文件名称查询文件、根据文件的inode编号查询文件、根据文件的权限查询文件、根据文件的拥有者/所属组身份查询文件、根据文件的时间戳查询文件、根据目录的层级来查询文件...)
4. 所有查找工具共同的特点, 查找的目录必须要有 **r** 和 **x** 权限 
5. **find查询的时候是遍历查询** , 所以效率低
- 语法格式
	- ```bash
		find 查询的目录 查询的条件 命令操作
		find /home -name "zhangsan" -print : 表示在/home目录下查询文件名是zhangsan的文件并且将其打印输出到屏幕上
		# 默认情况下可以不写 -print : 也是打印到屏幕上
		# 如果查询的目录不写, 表示在当前目录下查找 
		find -name "zhangsan"
	  ```

## 2.1 查询条件
### 2.1.1 基于文件名和 inode 编号查询
- 基于文件名进行搜索(支持通配符号)
	- ```bash
		find 目录 -name '文件名'
		find 目录 -iname '文件名' : 忽略大小写 
	  ```
- 基于文件inode编号搜索(一般是用来搜索硬链接文件的, 硬链接文件的inode编号是一样的)
	- ```bash
		find 目录 -inum 'inode编号'
	  ```

### 2.1.2 基于文件的拥有者/所属组身份查询
- 基于文件的拥有者身份查询
	- ```bash
		find 目录 -uid 'uid'
		find 目录 -user 'username'
	  ```
- 基于文件的所属组身份查询
	- ```bash
		find 目录 -gid 'gid'
		find 目录 -group 'groupname'
	  ```
- 查询没有拥有人/没有拥有组的文件 
	- ```bash
		# 不属于任何用户的文件: 文件还存在, 但是文件的拥有人或者拥有组已经被管理员删除了
		find 目录 -nouser
		find 目录 -nogroup 
	  ```
### 2.1.3 基于文件大小查询
- 基于文件大小进行查询
	- ```bash
		find 目录 -size +/-大小k/M/G
			5M  代表>4M <=5M, x-1<x<=x
			+5M  代表>5M
			-5M  代表<5M
			# -1M 比较特殊, 搜索的是空文件, 如果想搜索小于1M的文件, 就用-size 1M 
	  ```

### 2.1.4 基于文件类型查询
- 基于文件类型查询文件
	- ```bash
		find 目录 -type 类型
			f : 普通文件
			b : 块设备 
			c : 字符文件 
			d : 目录 
			l : 链接文件 
			p : 管道文件 
			s : 套接字文件
	  ```

### 2.1.5 基于文件权限查询
- 基于文件权限查询
	- ```bash
		find 目录 -perm 权限
			权限644 : 精确匹配644
			/644 : /644 表示只要匹配到任意一个权限即可, 里面是包含的关系. 比如查询的是/644, 如果文件的拥有人权限是4 也可以被查询到, 因为/644中的6是4和2
			-644 : 包含关系, 所有者必须包含rw,所属组必须包含r,其他人必须包含r, 才会匹配
			000 不关注, 600 只看拥有者, 仅在/或者-中使用
	  ```
### 2.1.6 基于文件时间戳查询
- 基于文件时间戳查询
	- ```bash
		find 目录 -atime 天数 : 根据文件访问时间搜索
			+7 代表7天机7天以上的时间
			-7 代表7天之内的时间
			7 代表7-8天, 包含7天
		find 目录 -mtime 时间 : 根据文件修改时间搜索
		find 目录 -ctime 时间 : 根据文件改动时间搜索(属性)
		
		find 目录 -amin 分钟
		find 目录 -mmin 分钟
		find 目录 -cmin 分钟
	  ```

### 2.1.7 基于逻辑组合类型查询
- 基于逻辑组合类型查询
	- ```bash
		find 目录 -a : 逻辑与, 默认情况下, 就是逻辑与
			例题: 下面两个同等效果
				find / -size +10k -a -size -50k .....
				find / -siez +10k -size -50k ....
		find 目录 -o : 逻辑或
		find 目录 -not/! : 非
	  ```

### 2.1.8 基于目录层级查询
- 基于目录层级查询
	- ```bash
		find 目录 -maxdepth 数字 : 最大搜索深度(最多往下找几层)
		find 目录 -mindepth 数字 : 最小搜索深度(从第几层开始匹配)
	  ```

## 2.2 在查找的文件基础上进行二次命令操作（动作）
- 操作 : 打印输出、查看详细信息（权限、大小）、删除、自定义命令操作
	- ```bash
		-print : 打印输出查到的文件 默认的操作
		-ls : 列出查找到的文件的详细信息
		-delete : 删除查找到的文件 
			对于delete来说, 如果删除的是目录, 目录不为空, delete无法删除掉
		-ok / -exec : 在查找到的文件基础之上做二次命令, 后面的命令是自己写的Linux命令
			-ok : 交互式执行
			-exec : 非交互式执行
			例如删除: find . -type f -ok/-exec rm -rf {} \;
				{} 表示前面查到的文件
				\; 固定语法
	  ```
- 案例 : 搜索/root目录下, 将没有其他人x权限的普通文件都加上x权限
	- ```bash
		[root@server ~]# find /opt/123/ -type f ! -perm /001
		/opt/123/test.sh
		[root@server ~]# find /opt/123/ -type f ! -perm /001 -exec chmod o+x {} \;
		[root@server ~]# ll /opt/123/test.sh
		-rw-r--r-x. 1 root root 0 Apr 19 22:59 /opt/123/test.sh
	  ```
- 案例 : 将/etc/目录下所有以.conf结尾的普通文件, 并且文件的拥有人是root用户的, 将其备份到/tmp目录下, 以.bak作为备份后的文件后缀
	- ```bash
		命令 : find . -maxdepth 1 -type f -user root  -exec cp -a {} /tmp/{}.bak \;
	  ```
